Using the resolver

The resolver takes a single URL and returns the page as text. Call resolve(url) and read what comes back; the inline code span in this sentence and the block below are different things, and a Markdown transform has to keep them different. Indentation inside the block is significant, so a transform that reflows it changes the meaning of the code it is supposed to be reproducing verbatim.

def resolve(url: str) -> str:
    if not url:
        raise ValueError("empty url")
    return fetch(url)

The block carries a language class, which a transform may either preserve on the fence or drop. Either is defensible; doing it inconsistently is not.
