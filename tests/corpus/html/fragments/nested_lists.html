Steps for a first run

This fragment exists for one property: the depth of a nested list, and the distinction between an ordered and an unordered marker one level down. A transform that flattens the nesting produces output that reads as a single sequence of eight steps, which is wrong, and it does so quietly.

  • Prepare the environment
    1. Create the virtual environment
    2. Install the development extra
  • Run the suite
  • Read the report
    • Failures first
    • Then skips, which are not failures but are not passes either

Text sits on the parent item beside the nested list on purpose: that is the shape a flattening bug most often mangles.
